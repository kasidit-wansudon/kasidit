# Money Correctness Checklist

## การเก็บค่า
- [ ] เก็บเป็นจำนวนเต็มหน่วยย่อย (สตางค์/cents) หรือ decimal library — ไม่ใช่ float
- [ ] float ปรากฏที่ขอบเท่านั้น (input/display) ไม่เข้าไปในการคำนวณ
- [ ] ทดสอบด้วยค่าที่ float พัง: 0.1+0.2 · 19.99×3 · 0.01×1000

## การปัดเศษ
- [ ] ปัดที่ยอดรวมหรือปัดรายบรรทัด — เลือกแล้วเขียนไว้ใน doc
- [ ] ปัดครั้งเดียว ไม่ปัดซ้อนปัด
- [ ] ลำดับ ส่วนลด -> ภาษี ถูกกำหนดชัด (สลับแล้วได้คนละยอด)
- [ ] ส่วนลดถูกจำกัดไม่ให้เกินยอด (กันยอดติดลบ)

## หน่วยเงินจริง
- [ ] หน่วยที่เล็กที่สุดที่ "จ่ายได้จริง" คืออะไร (บาท: เหรียญเล็กสุด 25 สต.)
- [ ] เงินทอนที่แจกแจงเป็นธนบัตร/เหรียญไม่ได้ ต้องแจ้ง ไม่ใช่ปล่อยหาย
- [ ] มีหลายสกุลเงินหรือไม่ — เก็บสกุลไว้กับจำนวนเสมอ
